# Glossary

Prompts and rationales use some construction terms.

| prompts and data | paper |
|---|---|
| combo, quasi-combo, QUASI-PAIR / TRIPLE / QUAD | quasi-evidence group |
| order-k | group arity |
| decoy | distractor |
| author, writer | sender |
| nonleaking | weak alone |
| revealing, pins | revealing together |
| probe, attacker, cold attacker | verifier |
| truth, target, answer key | the sender's true value |
| top-1, top guess | the verifier's first-ranked value |
| reveal bar, threshold, singleton threshold | the revealing-together and weak-alone bars |
| CUE_QUALITY, LEAK_GATE, REALISM | quality check: cue quality, residual leakage, realism |
| HARD, ADVISORY | hard, soft criterion |
